## CariPrompt 1.5.0 — panneau réorganisable, texte jusqu'à 400 pt

Prompteur multi-écrans **gratuit et open source** pour **macOS, Windows et Linux**.

### Nouveautés
- **Panneau de réglages réorganisable** : glissez un bloc par son en-tête pour le déplacer
- L'**ordre des blocs** est mémorisé dans les préréglages et les projets `.cariprompt`
- **Taille du texte jusqu'à 400 pt** (au lieu de 220)
- **Lecture / pause** passe sur **⌥ + Espace** (Alt + Espace sous Windows et Linux), et fonctionne aussi pendant la saisie

### Quel fichier choisir ?
| Système | Fichier |
|---|---|
| Mac Apple Silicon (M1 à M4) | `CariPrompt-1.5.0-macOS-AppleSilicon.zip` |
| Mac Intel | `CariPrompt-1.5.0-macOS-Intel.zip` |
| Windows, avec installation | `CariPrompt-1.5.0-Windows-Setup.exe` |
| Windows, sans installation | `CariPrompt-1.5.0-Windows-Portable.exe` |
| Linux, toutes distributions | `CariPrompt-1.5.0-Linux-x86_64.AppImage` |
| Debian / Ubuntu | `CariPrompt-1.5.0-Linux-amd64.deb` |

Vos textes et réglages des versions précédentes sont conservés.

### ⚠️ Application non signée
CariPrompt n'est pas signé avec un certificat Apple ou Microsoft (payants). Un avertissement s'affiche au premier lancement :
- **macOS** : Réglages Système › Confidentialité et sécurité › **Ouvrir quand même**, ou `xattr -cr /Applications/CariPrompt.app`
- **Windows** : **Informations complémentaires** › **Exécuter quand même**

Détails dans le [README](https://github.com/CaribouNathan/CariPrompt#installation--application-non-signée).
