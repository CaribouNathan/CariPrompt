## CariPrompt 1.7.0 — prises audio, coach de rythme, annulation

Prompteur multi-écrans **gratuit et open source** pour **macOS, Windows et Linux**.

### Nouveautés
- **Enregistrement audio** : chaque prise est nommée automatiquement et conserve heure, durée, script, position, vitesse et analyse
- **Gestion des prises** : renommer, verrouiller, annoter, marquer, lire, comparer, exporter
- **Coach de rythme** pendant la prise, discret et désactivable
- **Annulation et rétablissement** dans l'éditeur (⌘Z / ⌘⇧Z)
- Choix du micro dans les réglages

### Quel fichier choisir ?
| Système | Fichier |
|---|---|
| Mac Apple Silicon (M1 à M4) | `CariPrompt-1.7.0-macOS-AppleSilicon.zip` |
| Mac Intel | `CariPrompt-1.7.0-macOS-Intel.zip` |
| Windows, avec installation | `CariPrompt-1.7.0-Windows-Setup.exe` |
| Windows, sans installation | `CariPrompt-1.7.0-Windows-Portable.exe` |
| Linux, toutes distributions | `CariPrompt-1.7.0-Linux-x86_64.AppImage` |
| Debian / Ubuntu | `CariPrompt-1.7.0-Linux-amd64.deb` |

Vos textes et réglages des versions précédentes sont conservés.

### ⚠️ Application non signée
CariPrompt n'est pas signé avec un certificat Apple ou Microsoft (payants). Un avertissement s'affiche au premier lancement :
- **macOS** : Réglages Système › Confidentialité et sécurité › **Ouvrir quand même**, ou `xattr -cr /Applications/CariPrompt.app`
- **Windows** : **Informations complémentaires** › **Exécuter quand même**

Détails dans le [README](https://github.com/CaribouNathan/CariPrompt#installation--application-non-signée).
