## CariPrompt 1.3.0 — English / Français, thème clair ou sombre

Prompteur multi-écrans **gratuit et open source** pour **macOS, Windows et Linux**.

### Nouveautés
- Interface en **anglais** (par défaut) ou en **français** : menu *View › Language* sur macOS, bouton **☰** sous Windows et Linux
- **Apparence** Système (par défaut), Claire ou Sombre
- Bouton **☰** dans la barre de titre sous Windows et Linux (Fichier, Prompteur, Apparence, Langue, À propos, Quitter)
- Meilleur contraste en mode sombre

### Quel fichier choisir ?
| Système | Fichier |
|---|---|
| Mac Apple Silicon (M1 à M4) | `CariPrompt-1.3.0-macOS-AppleSilicon.zip` |
| Mac Intel | `CariPrompt-1.3.0-macOS-Intel.zip` |
| Windows, avec installation | `CariPrompt-1.3.0-Windows-Setup.exe` |
| Windows, sans installation | `CariPrompt-1.3.0-Windows-Portable.exe` |
| Linux, toutes distributions | `CariPrompt-1.3.0-Linux-x86_64.AppImage` |
| Debian / Ubuntu | `CariPrompt-1.3.0-Linux-amd64.deb` |

Vos textes et réglages de la 1.2 sont conservés.

### ⚠️ Application non signée
CariPrompt n'est pas signé avec un certificat Apple ou Microsoft (payants). Un avertissement s'affiche au premier lancement :
- **macOS** : Réglages Système › Confidentialité et sécurité › **Ouvrir quand même**, ou `xattr -cr /Applications/CariPrompt.app`
- **Windows** : **Informations complémentaires** › **Exécuter quand même**

Détails dans le [README](https://github.com/CaribouNathan/CariPrompt#installation--application-non-signée).
